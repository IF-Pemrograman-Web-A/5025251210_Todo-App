# To-Do-List PWA

Todo app berbasis PHP + MySQL yang bisa di-install dan tetap bisa dibuka saat offline

## Fitur-Fitur PWA Baru
- Web App Manifest + icons
- Service Worker
- Strategi caching per resource
- Tombol Install

## Strategi Caching
1. Precache saat install tujuannya adalah kita menyiapkan html statsi yang akan tersedia saat offlune
2. Menggunakan network terlebih dahulu , kemudian jika network tidak ada kita menggunakan cache , saat cache kosong baru digunakan offline html
